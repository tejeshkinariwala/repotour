# Changelog

All notable changes are listed here. The format follows Keep a Changelog.

## [0.1.0] - Unreleased

### Added
- `repotour` CLI: `build`, `scan`, `check`, `init`, `install-skill`.
- Analyzers for Python and JavaScript/TypeScript; a generic analyzer for other text files.
- Role assignment with built-in rules and per-repo overrides.
- Single-file offline HTML viewer with parts, problems, stories, files and guide.
- Auto mode: a tour with no written content.
- Claude Code skill `/repotour` and plugin packaging.
- `scripts/leak_check.py` and `scripts/sync_skill.py`.
